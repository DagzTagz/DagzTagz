### 🍥 public work

**[dagztagz-hypothesis-engine](https://github.com/DagzTagz/dagztagz-hypothesis-engine)** · Python · Apache-2.0 · v0.3.x  
Open-source system for **generating, verifying, and testing scientific hypotheses**. Powered by Grok (xAI) in live mode — not an official xAI product. Dry-run first (`$0`). Local retrieval only; no silent web literature scrape.

**[Dagz-Scaffold](https://github.com/DagzTagz/Dagz-Scaffold)** · Python · MIT · v0.1.0  
Grok Build CLI harness / **The Inspector**. A persist is not done because the chat said so. Need `plan.md`, code, `evidence.md`, `critic.md`, and `score.json`. Critic verdicts: `REJECT` / `ACCEPT WITH WAIVERS` / `ACCEPT`. Build-in-public test environment.
